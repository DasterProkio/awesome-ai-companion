# Getting Started

Pick the path that matches your comfort with code.

## No Code

Start with a phone-simulator app such as [SullyOS](https://github.com/qegj567-cloud/SullyOS), [whale小手机](https://github.com/whale-Yd00/freeapp), or [ZeroChat](https://github.com/sh1nny0u/ZeroChat). Add an API key to get persona, memory, and proactive messaging without assembling the stack yourself.

## Some Tinkering

Start with [RikkaHub](https://github.com/rikkahub/rikkahub) on Android or [Kelivo](https://github.com/Chevey339/kelivo), then add a heartbeat component such as [dylan-heartbeat](https://github.com/callie0313/dylan-heartbeat). Add a memory layer such as [ai-memory-gateway](https://github.com/garan0613/ai-memory-gateway) when conversation history becomes too large.

## Full Stack

Use [Headlong](https://github.com/laude-institute/headlong) (for persistent agency and inner monologue loops) or [AstrBot](https://github.com/AstrBotDevs/AstrBot) (for multi-platform IM channels) as a backbone, connect memory through projects such as [Aelios](https://github.com/wusaki0723/Aelios) or [Paramecium](https://github.com/Shitsuten/paramecium), and add voice through [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS). End-to-end guides such as [not-fade-away](https://github.com/heyxiaoc/not-fade-away) and [cloud-and-island](https://github.com/cocoRaina/cloud-and-island) show how the pieces fit together.
