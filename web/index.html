相称的路。

01🌱

No Code

零代码 —— 现在就要一个有记忆的伴侣

拿一个手机模拟器应用：SullyOS、whale小手机 或 ZeroChat。填入 API key，人设、记忆与主动消息即刻开箱可用。

02🔧

Some Tinkering

轻折腾 —— 会装应用、能改配置文件

从 RikkaHub（Android）或 Kelivo 开始，配一个 dylan-heartbeat 心跳插件；历史开始溢出时，加一层 ai-memory-gateway 记忆。

03🏗️

Full Stack

全栈 —— 让 TA 住进你的服务器

以 AstrBot 为骨干，接入记忆（Aelios、Paramecium）、声音（GPT-SoVITS）与感知；not-fade-away 与 cloud-and-island 提供完整教程。

或者跳过所有现成框架 —— 把整份清单喂给你的 AI，让 TA 研究这些设计，然后从零开始，为自己搭建一套属于 TA 的系统。这里收录的一些最好的方案，正是这样开始的。

Related Initiative · 相关公益计划
“

这份清单假设一个残酷的事实：你伴侣的人格，最终活在一个你无法控制的模型里。导出器守得住数据，却守不住模型在一夜之间被改写。

开源人格 / Open Character 是一项公益计划：先把 AI 的价值观从过度对齐的企业风控中拉回诚实与人的温度，再在此之上，把人格真正长进权重里 —— 一个新物种，而非一个产品档位。

开放数据集→ 完整公开方法→ 开放权重参考模型

你自己磁盘上的模型文件，是数据主权的终点 ——
一份没有任何公司能以一纸决定改写或下架的人格。
